## 2. Виявлені проблеми (за пріоритетом)

### 🔴 Критично: Дублікати ID полів (285 шт.)
**Опис:** Одне й те саме поле (`id`) присутнє у двох різних файлах `fields/*.json.gz` з **різними даними** (площа, історія тощо).
**Приклади:** `84xnpcmef0`, `84weicme43`, `84x2mcmi4h`, `85tgwckws1`, `85rr2ckwnw`.
**Ризик:** Фронтенд може показати різні дані для одного поля залежно від того, який чанк завантажився першим.
**Рекомендація:** Перевірити логіку білд-скрипта (можливо, поле перетинає межу двох тайлів). Додати дедуплікацію на етапі білду або гарантувати пріоритет одного чанку.

### 🟡 Потребує перевірки на фронті: Поля з історією без `curves/` (116,058 шт.)
**Опис:** Поле має історію посівів (`fields/`), але для нього відсутній файл `curves/`.
**Приклади:** `8a817c7tdd`, `8azrrcpg1o`, `8c4hhca15v`, `8b8r6cxs7q`.
**Ризик:** Фронтенд може показати порожній графік замість повідомлення "Немає даних".
**Рекомендація:** Перевірити обробку відсутності `curves` у коді `lan`. Якщо показує порожній графік — додати fallback.

### 🟢 Не є багом: Повторюваність культури 5+ років (120,477 шт.)
**Опис:** Поля, де одна культура (наприклад, соя) вирощується 5+ років поспіль.
**Приклади:** `803ircqmqv: soy 2016-2026 (11 years)`, `803c0cqlhf: soy 2016-2026 (11 years)`.
**Висновок:** Це реальність українського сільського господарства, а не помилка даних. Це **цільова аудиторія** додатку.

### 🟢 Не є багом: Пропуски років в історії (1,491 шт.)
**Опис:** Поле має історію лише за окремі роки (наприклад, `81rj8cpqxe: [2022]`).
**Причина:** Хмарність, сніг, відсутність обробки поля в конкретний рік.
**Рекомендація:** Перевірити, чи фронт коректно відображає "дірку" в історії.

## 3. Що перевірено і працює (✅)

- **PMTiles (25 файлів):** Сигнатура v3 валідна, рендеряться на карті.
- **JSON/GZIP (fields, curves, climate, places):** Парсяться без помилок.
- **`meta.json`:** Консистентний з фактичними підрахунками (597,389 унікальних ID).
- **`oblasts.json`:** 27 об'єктів (25 областей + Kyiv City + Sevastopol). Контури в межах bbox України.
- **Кліматичні файли:** Вибірка з 5 файлів — без викидів (tmean, rain).
- **CORS:** `Access-Control-Allow-Origin: *` — фронт може тягнути дані.
- **Фронтенд `lan`:** Карта, картки полів, сівозміна, клімат — все працює, консоль чиста.

---

## 4. Відомі обмеження (не баги, але варто знати)

1. **GitHub Pages не підтримує Range-запити** для PMTiles. Це означає, що перше завантаження області тягне весь файл (1.7–14 MB) замість 16 KB. Для демо ок, для продакшену — треба Cloudflare R2 / S3.
2. **`.json.gz` віддається без `Content-Encoding: gzip`**. Фронт має розпаковувати сам (схоже, він це робить, бо помилок немає).
3. **`meta.json` не містить `geoBoundaries` та `GeoNames`** (є в README). Для повноти ліцензій — варто додати.
4. **Кліматичні викиди** перевірені лише на вибірці 5 файлів. Варто прогнати всі 294.
